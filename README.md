# QuickLook.Plugin.SphereViewer

Preview 360° photos and videos on Windows without opening an editor: select a file in Explorer, press
<kbd>Space</kbd>, and drag to look around.

This is a plugin for [QuickLook](https://github.com/QL-Win/QuickLook), the free app that brings macOS-style
Quick Look to Windows: pressing <kbd>Space</kbd> on a file in Explorer shows a preview of it. The plugin
adds 360° support, including Insta360's own unstitched `.insp`, `.insv` and `.lrv` files, stitched on the
fly with the horizon kept level.

## Supported files

| File | Shown as |
|---|---|
| `.jpg` / `.jpeg` with `GPano:ProjectionType = equirectangular` in its XMP (in-camera stitched 360° photos, most 360° apps) | Sphere |
| Insta360 `.insp` (unstitched photo: both fisheye images side by side) | Sphere, stitched on the fly |
| Insta360 `.lrv` (low-resolution video copy) | Spherical video with sound |
| Insta360 `.insv` (unstitched video) | Spherical video, played from the `.lrv` copy the camera writes next to it |

Ordinary photos and videos are left to QuickLook's built-in viewers. An `.insv` without its `.lrv`
also goes to the built-in video viewer, which shows one lens.

For `.insp`, `.lrv` and `.insv` the toolbar has a button that shows the original fisheye frame
unprojected; **360°** or <kbd>Esc</kbd> returns to the sphere.

## Install

**Prerequisites:** [QuickLook 4.x](https://github.com/QL-Win/QuickLook/releases/latest) — install it first; the plugin
is installed through QuickLook itself. It also needs the Microsoft Edge WebView2 Runtime, which Windows 10 and 11
already have.

1. Download `QuickLook.Plugin.SphereViewer.qlplugin` from
   [Releases](../../releases).
2. Select it in Explorer, press <kbd>Space</kbd> and click **Click here to install this plugin.**
3. Click **Restart now...** when the installation is done.

## Controls

- Drag to look around, mouse wheel to zoom.
- Arrow keys rotate and <kbd>+</kbd>/<kbd>-</kbd> zoom once the preview has focus.
- <kbd>Space</kbd> or <kbd>Esc</kbd> closes the preview, as usual in QuickLook.

## Limitations

- The dual-fisheye lens model is calibrated for the **Insta360 X5** (separate profiles for photo and
  video modes). Other dual-fisheye cameras open with the same model, so their seam may be visible.
- The `.insv` preview is the camera's low-resolution `.lrv` copy (1664×832), not the full-resolution
  file. Keep the `.lrv` files next to the `.insv` files if you want previews.
- Unstitched `.insp`, `.lrv` and `.insv` files are levelled with the camera's own motion sensor data, so
  the horizon stays straight when the camera was held tilted. The view still follows the camera's heading:
  there is no stabilisation or direction lock. Files without sensor data are shown as recorded.

## Troubleshooting

Each preview adds one line to `%LOCALAPPDATA%\SphereViewer\log.txt` with the file, how it was shown and
how long it took, or the error.

## Building

The plugin is a .NET Framework 4.6.2 class library (WPF, WebView2) and builds on Windows:

```
git clone <this repository>
pwsh scripts/get-quicklook-common.ps1
dotnet build src/QuickLook.Plugin.SphereViewer.csproj -c Release
pwsh scripts/pack.ps1
```

`get-quicklook-common.ps1` fetches `QuickLook.Common` from the QuickLook release named in `quicklook-version.txt`,
so the plugin is built against the same library QuickLook ships. GitHub Actions does the same on every pull
request and uploads the `.qlplugin`. A monthly workflow opens an issue when QuickLook, Photo Sphere Viewer or
three.js has a newer version than the one used here.

The web viewer in `viewer/` can be opened in any browser through a local web server, for example
`viewer/index.html?src=../tests/fixtures/dual-fisheye.insp&projection=dualfisheye&video=0`.
The test images in `tests/fixtures/` are synthetic and generated by `tools/make-fixtures.py`.
